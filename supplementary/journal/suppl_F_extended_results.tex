\subsection{Paired-ARI uncertainty quantification}
\label{subsec:paired-ari-uncertainty}

The headline contrast between Salinas-A SWIR (paired ARI $= 0.766$)
and KSC under any mask (paired ARI $\approx 0.01$) carries the
band-fragile narrative of the paper. The audit issue
\texttt{CAOS\_LDA\_HSI\_Paper\#7} flagged that those point estimates
were reported without error bars. The table below closes that gap with
two independent uncertainty quantifications per (scene, mask) tuple:

\begin{itemize}
\item \textbf{Permutation null}: for each tuple, the masked-fit
dominant-topic vector is uniformly shuffled $N_{\text{perm}} = 1000$
times. Each shuffle yields an ARI under the null hypothesis ``the two
maps share no structure beyond marginal label proportions''. The
permutation $p$-value is the fraction of permuted ARIs at least as
large as the observed ARI.
\item \textbf{Bootstrap 95\% CI}: pixels paired in both maps are
resampled with replacement $N_{\text{boot}} = 1000$ times; each
resample yields an ARI; the 2.5--97.5 percentile band is reported.
\end{itemize}

Pixels are capped at $D = 10{,}000$ per tuple via random subsample
under a fixed seed (RNG seed 42); the permutation null is identical
in distribution to the full-population null at this sample size and
the bootstrap CI is conservative by a factor of $\sqrt{D / D_{\max}}$
when the full count exceeds $10{,}000$. The reproduction script is
\texttt{figures/source/build\_paired\_ari\_uncertainty.py} in the
companion code repository.

\input{paired_ari_uncertainty}

Every (scene, mask) tuple carries a permutation $p$-value below
$0.05$; 23 of 24 carry $p < 0.001$ (only Botswana / SWIR comes in at
$p = 0.003$). The Salinas-A / SWIR headline of $0.766$ has
95\% CI $[0.735, 0.800]$ --- the basis is genuinely
SWIR-robust on that scene. The KSC tuples all sit at observed
$\in [0.007, 0.013]$ with 95\% CIs that do not cross zero; the
null mean is exactly zero by construction, so KSC is significantly
\emph{non-zero} but still genuinely band-fragile relative to every
other scene's tighter alignment.

\section{Axis F-7 companion: per-class precision / recall}
\label{sec:per_class_pr}

The main paper reports macro F1 for the canonical topic-routed
classifier (axis F-1) but does not break out per-class
precision and recall. Per-class numbers expose which classes the
canonical basis explains well versus which classes share a topic
basin with another class.

The tables below report per-class precision, recall and F1 for the
topic-routed-\emph{hard} classifier (each pixel labelled with the
arg-max topic, each topic mapped to its arg-max label) under the
canonical fit
$K = \max(4, \min(12, n_{\text{classes}}))$,
$\alpha = 0.45$, $\eta = 0.20$, $Q + 1 = 13$ tokens. The numbers are
computed directly from the per-(scene)
\texttt{p\_label\_given\_topic\_dominant} joint counts in the
canonical pipeline output --- see
\texttt{figures/source/build\_per\_class\_pr\_table.py} in the
companion code repository for the reproduction script.

The macro averages mirror the F-7 KL-coupling pattern of
Table~\ref{tab:b7}: scenes where the canonical basis explains the
labels well (Salinas, Salinas-A) carry the higher macro F1; KSC's
macro F1 of 0.025 is the headline ``band-fragile'' result already
surfaced in the main paper, and the per-class breakdown shows
\emph{every} KSC class except one carries F1 $< 0.05$ --- the
canonical basis is genuinely unaligned to the KSC label set, not
just weakly aligned on a handful of classes.

\section{Axis F-12: external baseline deltas}

\begin{description}
\item[Status note (2026-05-15).] Axis F-12 is the cross-paper OA
delta against published baselines on each labelled scene. Per the
candor caveat documented in journal Suppl G §Reporting choices,
the per-paper train/test splits are not always comparable across
the literature, so a single $\Delta_s = \mathrm{OA}^{\text{this work}}_s
- \mathrm{OA}^{(\text{ref})}_s$ scalar can be misleading.
\textbf{We deliberately defer the F-12 table to a verification
appendix paired with the journal submission cover letter,} where
each reference's per-paper split (train fraction, fold count,
augmentation policy) can be reported alongside the OA delta.
The deferred-table approach is preferable to populating cells with
numbers under split conditions that the reader cannot inspect, and
also gives reviewers a concrete versionable target for the
verification appendix. The framework's F-12 \emph{definition} is
unchanged; only the per-scene table is deferred. See journal
Section~\ref{subsec:b12} in the main paper for the F-12 axis
description (it remains part of the framework's twelve-axis
declaration).
\end{description}
